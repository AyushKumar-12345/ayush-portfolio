## 🚀 Deep Dive: The 4 Flagship Production Systems

### 1. 🍔 Feasto — Production-Grade MERN Food Delivery & AI Concierge

> **Enterprise food delivery platform inspired by Swiggy/Zomato featuring dual customer/admin management portals, driver GPS tracking, and generative AI dish recommendations.**

```
[Customer Portal] ──► [Express REST API] ──► [Razorpay Payment Gateway (HMAC-SHA256)]
         │                      │
         ├─► [Gemini AI Chat]   ├─► [Leaflet Driver GPS Tracker]
         │                      │
         └─► [Admin Dashboard] ─┴─► [MongoDB Atlas Cluster + Cloudinary CDN]
```

- **Dual-Portal Decoupled Architecture:** Engineered an isolated customer application alongside an administrative operations dashboard for menu item inventory, real-time order lifecycle dispatching, and driver assignment.
- **Real-Time GPS Tracking:** Implemented live driver coordinate visualization using **Leaflet GPS** with custom map pins and path rendering.
- **Cryptographic Financial Integrity:** Integrated **Razorpay Payment Gateway** with HMAC-SHA256 server-side webhook signature validation, preventing payment tampering and race conditions across carts.
- **AI Concierge:** Embedded **Google Gemini 3.0 Flash API** to deliver context-aware meal recommendations based on dietary preferences and live menu inventory.
- **DevOps & Security:** Containerized with multi-stage **Docker**, role-based JWT access controls (RBAC), and automated **GitHub Actions CI/CD**.

### 2. 🏡 StayNest — Full-Stack Vacation Rental & Booking Marketplace

> **Full-stack property booking platform adopting MVC architecture with collision-proof reservation scheduling, cryptographic payments, and server-side PDF generation.**

```
[Guest Browser] ──► [EJS / Bootstrap 5 UI] ──► [Express MVC Controllers]
                             │                            │
                             ├─► [Passport.js Session]    ├─► [Blackout Calendar Engine]
                             │                            │
                             └─► [PDFKit Invoice Engine] ─┴─► [MongoDB Atlas + Razorpay]
```

- **Collision-Proof Booking Engine:** Engineered calendar state logic with interactive date-picker blackout scheduling, ensuring zero double-bookings or concurrent date collisions across listings.
- **Automated Server-Side Invoicing:** Automated PDF invoice compilation via **PDFKit**, dynamically embedding transaction IDs, property details, tax breakdowns, and host metadata upon payment verification.
- **Hardened Application Security:** Implemented session authentication with **Passport.js**, defensive input sanitization via **Joi** schemas, and HTTP security headers with **Helmet**.
- **Geospatial & Media Pipelines:** Integrated dynamic property reviews, location discovery, and optimized cloud media transformation via **Cloudinary**.

### 3. 📊 SmartHouse — California Property Valuation & Conformal ML Engine

> **Mathematically grounded Machine Learning service for California residential property valuation, delivering point estimates with distribution-free Split Conformal Prediction uncertainty bounds.**

```
[Property Features] ──► [Flask REST API (<20ms)] ──► [Input Validation Schema]
                                │
                                ├─► [XGBoost Gradient-Boosted Ensemble (R² = 83.93%)]
                                │
                                └─► [Split Conformal Prediction Engine (90% Guarantee ±$68k)]
```

- **Ensemble Predictive Accuracy:** Trained an optimized **XGBoost** regressor on 20,000+ California census records, achieving **$R^2 = 83.93\%$**, **$17.52\%$ MAPE**, and **\$30,245 MAE** on held-out test data.
- **Mathematically Guaranteed Uncertainty Bounds:** Integrated distribution-free **Split Conformal Prediction** guaranteeing **$90\%$ statistical coverage** ($\pm$\$68,169), providing actionable risk ranges rather than brittle point predictions.
- **Explainable AI (XAI):** Exposed feature attribution telemetry detailing how median income, housing age, and geographic coordinates drive property valuation.
- **Microservice Architecture:** Deployed via a low-latency (<20ms) **Flask REST API** with defensive schema checks, containerized via **Docker**, and backed by unit test coverage.

> **Full-stack enterprise AI knowledge platform orchestrating bounded multi-step reasoning, HNSW vector hybrid semantic search, and AST-guarded relational analytics.**

```
[React 18 TypeScript UI] ──► [FastAPI Core Gateway]
                                    │

    │                                                               │

    │                                                               │
    └─► [Evidence Citation Synthesis Engine]                        └─► [PostgreSQL Relational DB]
```

- **Bounded Multi-Step Orchestration:** Built with **LangGraph StateGraph**, orchestrating deterministic intent classification, dynamic tool invocation, and bounded recursive reasoning ($\le 4$ steps) with fallback timeouts.

- **5-Layer SQL AST Guardrail:** Designed safe read-only natural language SQL query generation with AST parsing via **sqlglot**, table whitelisting, keyword blacklisting, and row limit injection.
- **Enterprise Workspace UI:** Built a 3-pane client interface in **React 18** and **TypeScript** with streaming responses, markdown visualization, and containerized Docker Compose orchestration.

## ⚡ Performance, Accessibility & Quality Controls

- **Zero-Warning Codebase:** Verified with ESLint under `--max-warnings 0` and strict TypeScript compilation (`tsc --noEmit`).
- **Optimal Rollup Chunking:** Refined manual chunk distribution in `vite.config.ts`, cleanly splitting:
  - `vendor`: Core React & React-DOM runtime (`~141 kB`)
  - `animations`: Framer Motion physics engine (`~114 kB`)
  - `index`: Application logic & styles (`~120 kB`)
  - **Zero Circular Chunk Warnings** during production compilation.
- **Theme Persistence:** Dark and light theme modes stored in `localStorage` with system preference fallback (`prefers-color-scheme`).
- **Accessibility (A11y):** Keyboard escape listeners, ARIA dialog attributes (`role="dialog"`, `aria-modal="true"`), and high-contrast color ratios.

