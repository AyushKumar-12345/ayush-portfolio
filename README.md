### 3. 📊 SmartHouse — California Property Valuation & ML Inference Engine
- **Architecture:** Mathematically grounded Machine Learning inference service for residential property valuation in California.
- **Performance:** Achieved **$R^2 = 83.93\%$** and **$17.52\%$ MAPE** (\$30,245 MAE) using an optimized **XGBoost** gradient-boosted ensemble trained on 20,000+ property records.
- **Key Features:** Integrated distribution-free **Split Conformal Prediction** delivering mathematically guaranteed **90% confidence intervals** ($\pm$\$68,169), eliminating financial tail risk. Explainable AI (**XAI**) feature attribution telemetry and defensive input validation schemas.
- **DevOps:** Low-latency (<20ms) Flask REST API containerized with Docker and GitHub Actions CI.
- **Tech Stack:** Python, Flask, XGBoost, Scikit-learn, Pandas, NumPy, Docker, Split Conformal Prediction.
- **Links:** [🌐 Live Demo](https://smarthousepricepredictor.onrender.com) • [📦 GitHub](https://github.com/AyushKumar-12345/SmartHousePricePredictor)

- **DevOps:** Multi-stage Docker Compose orchestration and automated GitHub Actions CI/CD test suite.
- **Tech Stack:** Python, FastAPI, LangGraph, PostgreSQL 16, pgvector, React 18, TypeScript, Docker Compose.

## 🛠 Local Setup & Development

### 1️⃣ Prerequisites
- **Node.js:** v18.0.0 or higher
- **npm:** v9.0.0 or higher

### 2️⃣ Clone Repository
```bash
git clone https://github.com/AyushKumar-12345/ayush-portfolio.git
cd ayush-portfolio
```

### 3️⃣ Install Dependencies
```bash
npm install
```

### 4️⃣ Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5️⃣ Code Quality & Type Checks
```bash
# Type check TypeScript codebase
npm run type-check

# Run ESLint linter
npm run lint

# Build for production
npm run build

# Preview production build locally
npm run preview
```
